# NordCursor

NordCursor is a small native Windows utility that gently moves the mouse cursor after a configurable period of inactivity, helping keep the computer awake.

## Features

- Configurable inactivity delay
- Movement radius options: 1, 5, or 20 pixels
- Smooth, normal, and fast movement modes
- Compact dark interface inspired by Termius
- Minimizes to the Windows system tray
- DPI-aware rounded interface

## Usage

Download and run `NordCursor.exe`. No installation is required.

Use the tray icon to open, pause, resume, or exit the application.

## Source

The application is written in [AutoHotkey v2](https://www.autohotkey.com/). To run the source directly, install AutoHotkey v2 and launch `NordCursor.ahk`.

## Files

- `NordCursor.ahk` — application source
- `NordCursor.exe` — ready-to-run Windows build
- `assets/` — application icon files

## Platform

Windows 10 or Windows 11.
